种草引流内容制作销售跟进协作与情报

01种草引流 Agent

把评论里的意向，接成可跟进的线索。

适用客户
小红书、抖音发种草内容，引流至私域的公司，如装修、教育、加盟、医美、电商。
核心痛点
发完内容还要盯评论区。问价、要联系方式、咨询加盟，人工逐条回复、引导加企微；量大时忙不过来，漏接就意味着流失。
输入
要监控的平台账号；意向关键词，如“多少钱”“怎么买”“怎么加盟”“联系”；企微或私域入口。
输出
自动扫描评论区 → 识别留资意向 → 回复并引导进入企微或私域 → 添加后发送加盟表或产品手册做初筛 → 低意向过滤，高意向转人工。

02去 AI 味种草文案批量生成

让卖点、痛点、利益点各就其位。

适用客户
需要在多个平台发布种草内容的运营团队。
核心痛点
AI 仿写重复率高、AI 味重；浅层种草逻辑混乱，卖点、痛点、利益点的位置安排不清。
输入
目标客户画像；产品功能；价格；活动机制。
输出
生成适配小红书、抖音、视频号的种草文案，内置去重和去 AI 味处理；可指定“焦虑钩子”或“功能实测”等表达方向。

03商品主图 / 详情页自动生成

从一张商品图，延展整套展示内容。

适用客户
电商公司，以及建材、食品、设备等有商品展示需求的传统行业。
核心痛点
每上一个新品都要拍主图、写详情页。外包贵、自己做慢，SKU 一多就跟不上。
输入
随手拍或白底商品图；产品卖点；规格参数。
输出
生成抖音、淘宝风格的商品主图，提供多套模板选择；同步产出详情页文案与排版建议。

04直播话术 / 短视频脚本自动生成

把商品信息，组织成完整的讲述节奏。

适用客户
直播团队、短视频运营团队。
核心痛点
每场直播、每条视频都要从零组织卖点与话术，费时间；团队里也并非每个人都擅长写转化型脚本。
输入
商品信息；活动机制，如“今天直播间 8 折＋买一送一”；目标时长。
输出
整场直播话术串：安排抛钩子、推活动、促单的时机；或生成短视频脚本，包含分镜头、口播与字幕建议。

05销售线索自动跟进 Agent

让每一条留资，都有明确的跟进状态。

适用客户
加盟、教育、医美、企业服务等行业的销售团队。
核心痛点
每天收到几十上百条留资或表单，销售跟不过来，线索长期无人回应；老板也不清楚哪些已跟进、哪些无人管。
输入
留资渠道，如企微、表单、电话；跟进节奏规则。
输出
自动发送跟进消息 → 记录客户状态 → 分类打标签 → 低意向自动降级，高意向立即提醒销售介入。

06会议纪要自动整理与待办提醒

把会上说过的事，变成会后可跟踪的待办。

适用客户
团队协作较多、开会频繁的公司。
核心痛点
会上分配了任务，转头就忘；事后翻记录，也很难快速找到谁负责什么、何时完成，老板无法掌握落实情况。
输入
会议录音或会议纪要文本；也可直接使用飞书、钉钉会议自动转录内容。
输出
提取每个人的待办事项、截止时间与优先级 → 会后推送至企微、钉钉或飞书 → 到期前自动提醒 → 全局查看待办进度。

07多平台客服统一工作台与负反馈预警

统一接待入口，及时发现重复出现的问题。

适用客户
在多个平台销售产品或服务的公司。
核心痛点
抖店、淘宝、京东、小红书、企微各有后台，客服反复切换；负反馈分散，运营看不到趋势，往往到大面积爆发才察觉。
输入
各平台店铺或账号授权；负反馈关键词库。
输出
多平台客服接入统一后台回复；同类负反馈达到设定阈值时自动预警。例如，3 天内有 10 人反馈“包装破损”，自动通知运营。

08行业 / 竞品情报自动采集推送

把每天刷信息，变成定时收到有效更新。

适用客户
需要持续关注招投标、加盟、竞品动态或行业资讯的公司。
核心痛点
每天人工查看多个网站，追踪新标的、竞品上新、改价或广告动作，费时间且容易遗漏。
输入
指定采集源；关键词；推送频率。
输出
定时采集、整理、去重后推送至企微、钉钉或飞书；可选择“有新内容才推送”，或“每天早上 9 点汇总推送”。
